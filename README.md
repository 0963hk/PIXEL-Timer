# PIXEL-Timer

一个无需安装的像素风专注计时器。所有任务、待办和记录都只保存在当前浏览器中。

## 开始使用

直接用浏览器打开 [index.html](./index.html)，即可开始使用；也可以访问 [在线版](https://0963hk.github.io/E-INK-Timer/)。

1. 在 `TASK` 输入正在做的事。
2. 设置分钟数，点击 `START`。
3. 中途完成请点击 `DONE`，系统会记录实际专注时长；倒计时结束也会自动记录。
4. `RESET` 只重置计时，不会保存本次记录。

进行中的专注或休息会自动保存状态。刷新页面或重新打开后，计时器会恢复；如果倒计时在页面关闭期间已经结束，系统会自动补记该轮专注。

勾选 `COUNT UP` 可改用正计时，适合时长未定的任务。

如需规律休息，可勾选 `BREAK CYCLE` 并设置 `REST` 分钟数。每轮倒计时自然结束后，工具会保存专注记录、播放提示音并弹出休息提醒，同时自动开始休息倒计时；休息结束会再次提示你开始下一轮。该模式不适用于正计时，提前点 `DONE` 也不会自动开始休息。

## 常用功能

- `THEME`：从菜单选择 E-INK、深色、Synthwave 或 Sakura Arcade 主题；选择会自动保存，下次打开时恢复。每个主题都配有对应风格的像素 Miku 水印：E-INK 使用黑白电子墨水质感，深色主题采用石墨与青色细节，Synthwave 使用青紫霓虹造型，Sakura Arcade 使用粉色樱花造型。Synthwave 包含启动扫描、运行网格、暂停呼吸灯、最后一分钟提醒、完成像素爆发、重置 CRT 收束和禅模式光晕。Sakura Arcade 使用樱花掌机式双色像素短条，专注计时运行时会在全屏均匀维持约 15–20 片缓慢飘落的像素花瓣，暂停、完成或重置后自动消失；禅模式使用无边框的纯粉色背景并保留花瓣。两套动态主题都遵循系统的“减少动态效果”设置。
- `ZEN` 或点击大号时间：进入/退出禅模式；禅模式下也可按 `Enter` 退出。
- `DASHBOARD`：左侧包含当前时间、下班倒计时、`TIME TARGET`、天气、待办、倒数日和今日记录；窄屏时可用左上角按钮收起。
- `TIME TARGET`：填写事件和具体日期时间，实时查看距离该时刻还剩多少小时/分钟；点击 `[E]` 可修改目标的日期、小时和分钟。
- `INBOX`：右侧快速收集临时事项，不会停止当前计时；点击 `→` 可转为待办。
- 天气：允许浏览器定位权限后自动获取；点击天气卡片可刷新。
- 待办与倒数日：填写内容后点 `+` 添加，点击 `[x]` 删除；到设定下班时间后，已完成待办会自动清除，未完成事项会保留。
- 今日记录：可编辑 `[E]`、删除 `[X]`，或点 `[SAVE]` 导出当天 `.txt` 日志。
- `SHARE IMG`：将今日专注统计图保存为 PNG 图片，并保留当前主题对应的像素 Miku 水印；Sakura Arcade 会使用专属樱花边框。
- `DAY WRAP-UP`：在 `END OF TODAY` 前 15 分钟弹出一次，提示核对今日记录、处理 INBOX，并可保存明日三件事；保存的事项会在明天自动加入 TODO。
- `DATA BACKUP`：点击 `[EXPORT]` 将全部记录、待办、倒数日、目标和设置导出为 `.json`；点击 `[RESTORE]` 可校验并恢复备份，恢复操作会替换当前数据。
- `RESET APP`：位于左侧组件最下方。确认后会清除本工具的全部本地数据与设置，并恢复初始页面；此操作无法撤销。

## 自动归档

在今日记录底部设置 `AUTO-ARCHIVE AT` 时间（默认 `00:00`）。页面保持打开时，工具会每天自动导出对应日期的日志和统计图片；设为午夜时导出前一天的数据。

浏览器可能会询问是否允许多个下载，请允许以完成自动导出。自动归档不会删除已有记录。

## 数据说明

数据使用浏览器 `LocalStorage` 保存，不会上传到服务器。清除浏览器网站数据、换浏览器或使用无痕模式，都可能导致记录无法保留；建议定期使用 `DATA BACKUP` 的 `[EXPORT]` 保存完整备份。`[SAVE]` 和 `SHARE IMG` 适合导出当天摘要，但不能用于恢复全部数据。

## 运行环境

推荐使用 Chrome、Edge 或 Safari。天气功能需要网络和定位权限；图片导出依赖网络加载的字体与截图组件。
